# Keytone

[English](README.md)

在浏览器里用电脑键盘弹电子琴。无需服务器，无需安装。

## 功能

- 17 种精选音色：三角钢琴、电钢琴、风琴、羽管键琴、弦乐、合唱、长笛、铜管、吉他、槌击乐器、八音盒和合成器
- 用电脑键盘弹奏，也可以用鼠标点击或拖动屏幕上的琴键
- 按住生效的八度键和延音踏板，按键都可以自定义
- 音量、力度和混响控制
- 中英文界面
- 设置自动保存在浏览器里

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

然后打开 http://localhost:5173。

## 怎么弹

| 按键 | 音 |
|---|---|
| `Z X C V B N M` | C D E F G A B（C3–B3） |
| `S D G H J` | C# D# F# G# A# |
| `, . /` 和 `L ;` | C4 D4 E4 和 C#4 D#4 |
| 按住 `左 Shift` / `右 Shift` | 降 / 升一个八度 |
| 按住 `空格` | 延音踏板 |

八度键和延音键可以在 **按键** 设置里修改。升 / 降两个八度的键默认不绑定。

也可以用鼠标点击，或在屏幕琴键上拖动。
