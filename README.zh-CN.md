# Keytone

[English](README.md)

在浏览器里用电脑键盘弹电子琴。无需服务器，无需安装。

**[▶ 在线体验](https://jikunliu101.github.io/keytone/)**：支持桌面浏览器和横屏手机（已在 Chromium 内核浏览器和 iPhone 上测试）。先点击、轻触页面或按一下任意键，才会开始出声。

## 功能

- 17 种精选音色，分为 5 个家族：钢琴、风琴与古键琴、合奏与管乐、拨弦与槌击、合成器
- 3D 电子琴造型，琴键后立着一块磨砂玻璃，弹奏时柔和的光柱在玻璃上升起，可选冷色（极光）或暖色（琥珀）
- 玻璃上显示琴谱：可以看简谱弹，也可以跟着落向琴键的下落光柱弹
- 简谱按拍等宽排版，每行只放完整的小节（每行 8–32 拍可选）
- 音符下面显示歌词，中英文都行；练习模式下当前的字会跟着音一起亮
- 练习模式：琴谱等你弹对才前进；不开练习时，下落模式会统计"完美 / 失误"
- 琴谱编辑器：左边是琴谱，右边是旋律和歌词的文本；用数字键写谱，可以框选、复制粘贴、撤销，曲谱保存在浏览器里，可以导入导出文本文件
- 用电脑键盘弹奏，也可以用鼠标点击、拖动屏幕琴键，或者用手指（支持多指）
- 按住生效的八度键和延音踏板，按键都可以自定义
- 音量、力度（用 pp 到 fff 的力度记号显示）、混响和光条特效控制
- 中英文界面，设置自动保存在浏览器里
- 支持系统的"减少动态效果"设置，可以只用键盘或读屏软件操作

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

然后打开 http://localhost:5173。

## 怎么弹

| 按键 | 音 |
|---|---|
| `Z X C V B N M` | C D E F G A B（C3–B3） |
| `S D G H J` | C# D# F# G# A# |
| `, . /` 和 `L ;` | C4 D4 E4 和 C#4 D#4 |
| 按住 `左 Shift` / `右 Shift` | 降 / 升一个八度 |
| 按住 `A` / `'` | 降 / 升两个八度 |
| 按住 `空格` | 延音踏板 |

八度键和延音键可以在 **按键** 设置里修改；那里还列出了固定的快捷键（按 `F1` 打开）：练习时 Backspace 回到这一句开头（长按从头开始），Tab / Shift+Tab 切换下一首 / 上一首，Enter 播放下落模式，等等。

也可以用鼠标点击，或在屏幕琴键上拖动。

## 琴谱

在控制栏的 **琴谱** 里选 **简谱** 或 **下落**。内置两首曲子；点 **编辑琴谱…** 打开编辑器。

| 编辑器里 | 作用 |
|---|---|
| `1`–`7` | 音符（do re mi…） |
| `0` | 休止 |
| `-` | 把前一个音延长一拍 |
| `/` | 把刚输入的音减半（按两次是四分之一拍） |
| `.` | 加附点 |
| `↑` / `↓` | 升 / 降半音 |
| 按住八度键再按数字 | 低音 / 高音 |
| `←` `→`、`Backspace` | 移动、删除 |
| `Shift` + `←` `→`、拖动 | 框选音符（在琴谱或旋律文本里都行） |
| `Ctrl/⌘` + `C` `X` `V` | 以文本形式复制、剪切、粘贴音符 |
| `Ctrl/⌘` + `Z`，加 `Shift` | 撤销、重做 |

小节线按拍号自动画。每一拍一样宽，每行只放完整的小节，能放几个由控制栏里的 **每行拍数** 决定。

歌词写在旋律旁边的歌词框里，每个音对一项（拖长音符的 `-` 也算一个音，休止符不算）：一个汉字，或一个英文单词。`hap-py` 把一个词拆到两个音上，单独的 `-` 表示接着唱上一个字，`0` 表示这个音不唱。可以先写歌词再写音符：暂时对不上的部分会排在最后一个音后面等着。

导出的 `.txt` 文件使用一种简单的纯文本格式，见 [产品说明](docs/spec.zh-CN.md#105-文本格式)，歌词写在第二个 `---` 后面（[§11.3](docs/spec.zh-CN.md#113-歌词)）。

手机上（横屏）琴谱只能看不能编辑：简谱只显示一行，下落模式下键盘会自动滑到要弹的音。
