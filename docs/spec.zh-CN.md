# Keytone 产品说明

> 状态：第一、二、三版（琴谱，§10）均已实现并上线（2026-10-24）。英文版为正式版本：[spec.md](spec.md)。

Keytone 是一个纯浏览器运行的 app：把电脑键盘变成一台电子琴，内置少量精选音色。

## 1. 目标
- 先满足个人使用；以开源仓库发布，方便别人自己运行或部署。
- 纯前端。可在本地运行，并部署在 GitHub Pages 上。
- 桌面浏览器优先；手机和平板支持横屏弹奏。

## 2. 范围

### 第一版
- 17 种精选音色
- 电脑键盘弹奏（音符键固定）
- 鼠标点击屏幕琴键，支持按住拖动刮奏
- 按住生效的临时八度键
- 延音踏板
- 音量、力度滑块
- 混响开关
- 可自定义八度键和延音键

- 可收起的控制栏

### 第二版

## 3. 键盘映射

### 音符键
音符键是固定的。按物理键位（`KeyboardEvent.code`）识别，所以不受键盘布局影响。

不按八度键时：

| 键 | 音 | 键 | 音 |
|---|---|---|---|
| `Z` | C3 | `S` | C#3 |
| `X` | D3 | `D` | D#3 |
| `C` | E3 | | |
| `V` | F3 | `G` | F#3 |
| `B` | G3 | `H` | G#3 |
| `N` | A3 | `J` | A#3 |
| `M` | B3 | | |
| `,` | C4 | `L` | C#4 |
| `.` | D4 | `;` | D#4 |
| `/` | E4 | | |

`Z` 是默认八度的 1（do），`, . /` 是高音 1 2 3。

### 八度键
- 按住时生效，松开后恢复。
- 共 4 个，都可以重新绑定：

  | 功能 | 默认按键 |
  |---|---|
  | 降一个八度 | 左 Shift |
  | 升一个八度 | 右 Shift |
  | 降两个八度 | `A` |
  | 升两个八度 | `'` |

  `A` 和 `'` 分别在左右 Shift 外侧的上方，所以 ±2 八度键和 ±1 八度键左右对称。

- 所有按住的八度键的偏移量相加，结果限制在 −2 到 +2 之间。
  - 左右 Shift 同时按住 = 0。
  - +1 和 +2 同时按住 = +2。
- 每个音的音高在按下那一刻就确定了，之后按下或松开八度键都不会改变已经在响的音。
- 没有常驻的基准八度设置。不按八度键时，`Z` 始终是 C3。

### 延音
- 按住生效，默认空格，可以重新绑定。
- 按住延音时，松开的音会继续响，等松开延音键才停止。

### 输入处理规则
- 忽略按住不放时自动重复的按键事件。
- 对已映射的键阻止浏览器默认行为。否则空格会滚动页面，`/` 在 Firefox 里会打开快速查找。
- 窗口失去焦点时，停止所有音，并重置八度和延音状态。
- 焦点在输入框里时（例如按键绑定对话框）不触发音符。

### 音域
- C1–E6：38 个白键，加上对应的黑键。

### 控制项
- **音量**：总音量滑块。
- **力度**：键盘和鼠标都感知不到按键轻重，所以统一用一个固定力度，由滑块设置，默认约 100/127。
- **混响**：固定的轻度混响，可以开关。

## 6. 架构

用 TypeScript + React + Vite 开发，声音用 smplr，单元测试用 Vitest。

```
input/      键盘（物理键 → 动作）、鼠标（第二版加触屏）
   │           发出：noteOn(midi, velocity)、noteOff(midi)、八度/延音变化
core/       纯状态：按键映射、八度偏移、正在响的音、延音逻辑
   │
   ├─▶ audio/   AudioEngine（解锁 AudioContext、总音量、混响）
   │            Instrument 接口 + 17 种音色的注册表
   │
   └─▶ view/    与渲染方式无关的琴键布局（几何尺寸、标签）
                KeyboardView（CSS 3D，第一版）│ EffectsLayer（Canvas 2D，第二版）
ui/         React 控制栏、设置、多语言
```

设计原则：
- **统一的事件流。** 键盘、鼠标，以及以后的触屏和 MIDI，都只产生同一种音符事件。声音和画面只订阅这些事件，不直接读取输入设备。
- **纯逻辑核心。** 按键映射、八度计算、延音逻辑不依赖 DOM 和音频，可以单独写单元测试。
- **可替换的发声后端。** `Instrument` 接口包括 `load`、`start(midi, velocity)`、`stop(midi)`、`stopAll`。延音在核心层处理，不依赖 smplr，所以对所有后端效果一致，包括以后可能加的 Tone.js。
- **可替换的渲染层，保留升级 Three.js 的可能。** 琴键的几何尺寸在一个与渲染方式无关的模块里计算，渲染层只读取状态和事件。以后可以直接用 Three.js 视图替换 CSS 视图，输入、核心逻辑和声音部分都不用改。
- **音频解锁。** 浏览器要求用户先操作一次才能出声，所以第一次点击或按键时恢复 `AudioContext`。

## 9. 第二版需求

2026-10-21 确认。

### 9.1 光条效果
- **玻璃板**
  - 在琴键和机身面板之间的毡条上，立着一块透明度较高的磨砂玻璃板。
  - 玻璃板在画面里真正竖直：正对观众，与屏幕平行。
  - LCD 和音箱条留在玻璃后面，透过玻璃看过去是柔和模糊的。
- **光条**
  - 光条只出现在玻璃板上。
  - 按住琴键时，从玻璃底部对应琴键的位置向上长出一根发光的柱子，按得越久越长。
  - 松开后，柱子脱离底部，匀速继续上升，到玻璃顶边附近淡出，不会升出玻璃。
- **光晕**：每根光柱是一道柔和的光束，有明亮的光芯、较宽的外晕和渐隐的顶部拖尾；脱离底部后，下端也会变柔。
- **氛围**
  - 按住时，光柱与玻璃底边相接处会聚起一团光。
  - 按下瞬间迸出少量光点，按住期间持续向上飘，边飘边摆动、淡出。
  - 按住的键越多，玻璃底部升起的薄雾越明显。
- **颜色**
  - 来自同一个色系，而不是彩虹色。低音深、高音亮，每个音级再有一点偏移，让相邻的音能区分开。
  - 两种色调：**极光**（冷色：紫 → 蓝 → 冰白）和**琥珀**（暖色：橙 → 金 → 奶白）。
  - 在控制栏特效开关旁边切换。默认极光，和其他设置一起保存。
- **延音不影响光条**：光条只跟手指按住的时间走，与声音持续多久无关。
- **上升速度**：暂时固定，以后可能加滑块。
- **特效开关**放在控制栏里：
  - 默认开启。
  - 如果系统开启了"减少动态效果"（`prefers-reduced-motion`），默认关闭。
  - 和其他设置一起保存。
- **渲染方式**
  - Canvas 2D 放在玻璃板自身的 3D 平面里，光条自然带透视。
  - 琴键的横向位置直接取自与渲染方式无关的布局数据。
  - 松开后的光条在任何屏幕尺寸下，穿过整块玻璃所需的时间都相同。
  - 绘制由 NoteHub 的按键事件驱动，不会增加声音延迟。
  - 只有画面上还有东西时才运行动画循环。
- **性能**
  - 不使用 `shadowBlur`，也不每帧新建渐变（只有薄雾那一层例外）。所有柔光都来自小尺寸的光晕贴图，每种色调、每个音只生成一次，再用 `drawImage` 拉伸绘制。
  - 画布分辨率最高为设备像素的 1.5 倍。
  - 光点最多 48 个。
  - 琴键按下只对 `transform` 做动画；玻璃不使用混合模式。
  - 每个屏幕琴键都做了缓存（memo），弹一个音只重新渲染那一个键。

### 9.2 触屏输入
- 支持多指同时按，可以弹和弦。
- 手指在琴键上滑动时依次发声，和鼠标拖动一样。
- 力度使用固定的力度设置。

### 9.3 手机布局
- **何时启用**：使用触屏（粗指针）且 38 个白键全部放下时每个会窄于 32px，就启用紧凑布局。可用 `?layout=compact` 或 `?layout=full` 强制指定。
- **竖屏**：提示"请旋转手机"。
- **横屏**
  - 显示约 13 个白键（大约 2 个八度）。白键宽度约为（屏幕宽度 − 72px）/ 13；高度单独设定，琴键不会被压扁。
  - 琴键上方有一条 38 键的缩略导航条，拖动它来选择显示哪一段。
  - 控制栏浮在舞台上方，展开时不会改变琴键大小。
- **手机上**
  - 控制栏默认收起。
  - 隐藏电脑按键字母和按键提示。

### 9.4 部署
- 部署到 GitHub Pages：`jikunliu101.github.io/keytone`。
- 每次推送到 `main` 后，由 GitHub Actions 自动发布：安装、测试、构建、部署。
- Vite 使用相对路径（`./`）构建，同一份构建放在任何路径下都能用。

### 9.4a 手机声音

  - 在支持的浏览器上设置 `navigator.audioSession.type = "playback"`；
  - 第一次操作时播放一次很短的静音 `<audio>`；
  - 在点按、触摸、点击和按键时反复尝试 `AudioContext.resume()`，直到声音启动。
- 声音启动前，LCD 上显示"点击开始"提示。

## 10. 第三版需求：琴谱

2026-10-23 确认。

### 10.1 两种琴谱
在控制栏切换：**简谱 / 下落 / 关**，默认关。
- **简谱**：玻璃板变成谱架，上面放一张磨砂半透明的谱纸。
  - 每个音大约占一个白键宽，数字大小与之匹配。每行几小节、每页几行按玻璃大小自动计算（笔记本屏幕上约每行 5–8 小节、每页 4 行）；各行长度会自动平衡，最后一行不会只剩一小节。顶部显示标题、调号、拍号、速度。
  - 可开关显示每个音对应的电脑按键。
  - 光柱照常升起，但调淡，从谱纸后面透出来。
  - 用 ◀ ▶ 按钮或 PageUp / PageDown 翻页（练习模式下自动翻页）。
- **下落**：倒过来的光柱从玻璃顶部落向对应的琴键，取代升起的光柱。
  - 光柱长短跟音的时值走，颜色沿用光条色调，不显示按键。
  - 所有光柱都照常落下、沉入底边。按对：按下时底边溅起光点；没按到：下沉时变暗；按错：那个键的位置淡淡闪一下。
  - 只判断按对、按错、没按到，不检查按住多久。光柱到达底边前后约 0.25 秒内按下都算按对。
  - 播放控制：开始/暂停、从头开始、速度 50–150%、循环开关、开始前倒数一小节。app 不替你发声。
  - 弹完显示"完成"和 `完美: 42, 失误: 3`（英文 perfect / missing），不分等级。

### 10.2 练习模式
两种琴谱都能用，英文叫 "Practice"。
- 当前要弹的音高亮，弹过的变暗。
- 弹对才前进，弹错不前进。
- 休止和延长线自动跳过（不管节奏）；和弦要按齐；相同的音连着出现，要分别按。
- 简谱在下一个音落到下一页时自动翻页；下落光柱到底边停住等你。
- 弹完只显示"完成"。

### 10.3 编辑器
一个大面板，盖住玻璃板和控制栏，琴键仍露在下面。
- 输入和弹琴一样：数字键 1–7 输入音，`0` 是休止，`-` 把前一个音延长一拍。
- 按住八度键（沿用用户的自定义按键）输入高低音点。
- `/` 时值减半（按两次是四分之一拍），`.` 加附点。
- 方向键移动光标，退格删除，每输入一个音都会试听。
- 小节线按拍号自动画。
- 每首谱有调号（1=C … 1=B）、拍号（2/4、3/4、4/4、6/8）和速度。
- 超出 C1–E6 的音输入不进去。
- 附带一个同步的文本视图，用于复制粘贴。三连音和连音线不做。

### 10.4 音高和按键提示
- 1=C 时，不加八度点的 1–7 对应 Z–M 这一排（C3–B3）。
- 其他调号会移调，按键提示跟着换算，需要时会用到黑键和 Shift 标记。

### 10.5 文本格式
```
title: 生日快乐
key: C
time: 3/4
tempo: 100
pickup: 1
---
5./ 5// | 6 5 1' | 7 - - | 5./ 5// | 6 5 2' | 1' - - |
```
- `pickup:`（可选）第一个完整小节前的弱起拍数，用于从弱拍开始的曲子。
- `1`–`7` 是音，`0` 是休止，`-` 把前一个音延长一拍。
- `/` 减半，`//` 四分之一拍；`.` 附点。
- `'` 高八度，`,` 低八度，可叠加（`1''`）。
- `#` / `b` 升降半音（`#4`）。
- `[1 3 5]` 和弦（预留，只显示）。
- `|` 小节线可写可不写，显示时按拍号重新排版。

### 10.6 曲目管理
- 谱子保存在浏览器本地：新建、改名、复制、删除；导入导出 `.txt`。
- 内置只读曲目：《小星星》和《生日快乐》，要改先复制。之后用户会再提供曲子。
- 选中的曲目和琴谱设置会保存。

### 10.7 手机
- 只看不编辑：隐藏编辑按钮和按键提示。
- 手机上键盘（连同玻璃）会左右滑动，所以简谱和播放控件放在一层固定在屏幕上的图层里，位置对准玻璃的发光区域。
- 简谱只显示一行（音符格比桌面版窄），右侧是从头开始、翻页和隐藏按钮；隐藏后只留一个"显示琴谱"小按钮。
- 下落模式下琴键会稍微变矮，给玻璃留出下落空间；播放控件缩成右上角的一个小胶囊。
- 下落模式下，键盘窗口会滑到接下来约 1.2 秒要落下的音符处；在缩略条上手动拖动后暂停自动滑动，直到重新开始播放。
