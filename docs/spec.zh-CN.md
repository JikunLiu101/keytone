# Keytone 产品说明

> 状态：M1 和 M2（第一版）已实现（2026-10-21）。英文版为正式版本：[spec.md](spec.md)。

Keytone 是一个纯浏览器运行的 app：把电脑键盘变成一台电子琴，内置少量精选音色。

## 1. 目标
- 先满足个人使用；以开源仓库发布，方便别人自己运行或部署。
- 纯前端。先在本地跑，以后再上云。
- 桌面浏览器优先，手机以后再做。

## 2. 范围

### 第一版
- 17 种精选音色
- 电脑键盘弹奏（音符键固定）
- 鼠标点击屏幕琴键，支持按住拖动刮奏
- 按住生效的临时八度键
- 延音踏板
- 音量、力度滑块
- 混响开关
- 可自定义八度键和延音键
- 中英文界面
- 有立体感的琴键
- 可收起的控制栏
- 音色来源署名

### 第二版
- 弹奏时对应琴键升起光条或气泡（"梦幻钢琴"效果）
- 触屏输入
- 手机布局

### 以后
- 自托管样本
- 上云部署
- 外接 MIDI 键盘
- 可选的 Three.js 渲染

## 3. 键盘映射

### 音符键
音符键是固定的。按物理键位（`KeyboardEvent.code`）识别，所以不受键盘布局影响。

不按八度键时：

| 键 | 音 | 键 | 音 |
|---|---|---|---|
| `Z` | C3 | `S` | C#3 |
| `X` | D3 | `D` | D#3 |
| `C` | E3 | | |
| `V` | F3 | `G` | F#3 |
| `B` | G3 | `H` | G#3 |
| `N` | A3 | `J` | A#3 |
| `M` | B3 | | |
| `,` | C4 | `L` | C#4 |
| `.` | D4 | `;` | D#4 |
| `/` | E4 | | |

`Z` 是默认八度的 1（do），`, . /` 是高音 1 2 3。

### 八度键
- 按住时生效，松开后恢复。
- 共 4 个，都可以重新绑定：

  | 功能 | 默认按键 |
  |---|---|
  | 降一个八度 | 左 Shift |
  | 升一个八度 | 右 Shift |
  | 降两个八度 | 不绑定 |
  | 升两个八度 | 不绑定 |

- 所有按住的八度键的偏移量相加，结果限制在 −2 到 +2 之间。
  - 左右 Shift 同时按住 = 0。
  - +1 和 +2 同时按住 = +2。
- 每个音的音高在按下那一刻就确定了，之后按下或松开八度键都不会改变已经在响的音。
- 没有常驻的基准八度设置。不按八度键时，`Z` 始终是 C3。

### 延音
- 按住生效，默认空格，可以重新绑定。
- 按住延音时，松开的音会继续响，等松开延音键才停止。

### 输入处理规则
- 忽略按住不放时自动重复的按键事件。
- 对已映射的键阻止浏览器默认行为。否则空格会滚动页面，`/` 在 Firefox 里会打开快速查找。
- 窗口失去焦点时，停止所有音，并重置八度和延音状态。
- 焦点在输入框里时（例如按键绑定对话框）不触发音符。

### 音域
- C1–E6：38 个白键，加上对应的黑键。

### 控制项
- **音量**：总音量滑块。
- **力度**：键盘和鼠标都感知不到按键轻重，所以统一用一个固定力度，由滑块设置，默认约 100/127。
- **混响**：固定的轻度混响，可以开关。

## 5. 界面

### 布局
- 控制项放在页面顶部，可以收起：
  - 音色列表
  - 音量
  - 力度
  - 混响
  - 按键设置
  - 语言
  - 音色来源
- 琴键占满页面其余部分。

### 外观
- 琴键要有景深和立体感，像是在有限的视角里弹一台真实的电子琴。
- 第一版用 CSS 3D 透视、阴影和琴键厚度来实现。
- 细节以后再慢慢打磨。

### 琴键
- 显示 C1–E6。
- 高亮当前八度能弹到的键。
- 按下的键有视觉反馈。
- 每个键上用低对比度标出对应的电脑按键和音名，例如 `Z` 和 `C3`。

### 特效层
- 第一版在琴键上方预留一层透明画布。
- 第二版在这层画布上用 Canvas 2D 画升起的光条或气泡。

### 语言
- 支持英文和中文。
- 第一次打开时根据浏览器语言决定：`navigator.language` 以 `zh` 开头就用中文，否则用英文。
- 之后以 `localStorage` 里保存的选择为准。

### 本地保存
以下设置保存在 `localStorage`：
- 音色
- 音量
- 力度
- 混响开关
- 语言
- 按键绑定

所有读写都用 try/catch 包住，读不到时用默认值。

## 6. 架构

用 TypeScript + React + Vite 开发，声音用 smplr，单元测试用 Vitest。

```
input/      键盘（物理键 → 动作）、鼠标（第二版加触屏）
   │           发出：noteOn(midi, velocity)、noteOff(midi)、八度/延音变化
core/       纯状态：按键映射、八度偏移、正在响的音、延音逻辑
   │
   ├─▶ audio/   AudioEngine（解锁 AudioContext、总音量、混响）
   │            Instrument 接口 + 17 种音色的注册表
   │
   └─▶ view/    与渲染方式无关的琴键布局（几何尺寸、标签）
                KeyboardView（CSS 3D，第一版）│ EffectsLayer（Canvas 2D，第二版）
ui/         React 控制栏、设置、多语言
```

设计原则：
- **统一的事件流。** 键盘、鼠标，以及以后的触屏和 MIDI，都只产生同一种音符事件。声音和画面只订阅这些事件，不直接读取输入设备。
- **纯逻辑核心。** 按键映射、八度计算、延音逻辑不依赖 DOM 和音频，可以单独写单元测试。
- **可替换的发声后端。** `Instrument` 接口包括 `load`、`start(midi, velocity)`、`stop(midi)`、`stopAll`。延音在核心层处理，不依赖 smplr，所以对所有后端效果一致，包括以后可能加的 Tone.js。
- **可替换的渲染层，保留升级 Three.js 的可能。** 琴键的几何尺寸在一个与渲染方式无关的模块里计算，渲染层只读取状态和事件。以后可以直接用 Three.js 视图替换 CSS 视图，输入、核心逻辑和声音部分都不用改。
- **音频解锁。** 浏览器要求用户先操作一次才能出声，所以第一次点击或按键时恢复 `AudioContext`。

### 9.1 光条效果
- **玻璃板**
  - 在琴键和机身面板之间的毡条上，立着一块透明度较高的磨砂玻璃板。
  - 玻璃板在画面里真正竖直：正对观众，与屏幕平行。
  - LCD 和音箱条留在玻璃后面，透过玻璃看过去是柔和模糊的。
- **光条**
  - 光条只出现在玻璃板上。
  - 按住琴键时，从玻璃底部对应琴键的位置向上长出一根发光的柱子，按得越久越长。
  - 松开后，柱子脱离底部，匀速继续上升，到玻璃顶边附近淡出，不会升出玻璃。
- **光点**：按下的瞬间，从琴键顶部迸出少量小光点。
- **按音高分颜色**：一个八度内的 12 个音对应一圈彩虹色，同一个音在不同八度颜色相同。
- **延音不影响光条**：光条只跟手指按住的时间走，与声音持续多久无关。
- **上升速度**：暂时固定，以后可能加滑块。
- **特效开关**放在控制栏里：
  - 默认开启。
  - 如果系统开启了"减少动态效果"（`prefers-reduced-motion`），默认关闭。
  - 和其他设置一起保存。
- **渲染方式**
  - Canvas 2D 放在玻璃板自身的 3D 平面里，光条自然带透视。
  - 琴键的横向位置直接取自与渲染方式无关的布局数据。
  - 松开后的光条在任何屏幕尺寸下，穿过整块玻璃所需的时间都相同。
  - 绘制由 NoteHub 的按键事件驱动，不会增加声音延迟。

### 9.2 触屏输入
- 支持多指同时按，可以弹和弦。
- 手指在琴键上滑动时依次发声，和鼠标拖动一样。
- 力度使用固定的力度设置。

### 9.3 手机布局
- **竖屏**：提示"请旋转手机"。
- **横屏**
  - 显示约 2 个八度，琴键大小适合手指。
  - 琴键上方有一条 38 键的缩略导航条，拖动它来选择显示哪一段。
- **手机上**
  - 控制栏默认收起。
  - 隐藏电脑按键字母和按键提示。
